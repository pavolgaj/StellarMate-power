# StellarMate-power
Direct control of output DC ports of StellarMate Pro

### Usage:
```
  ./smpro-power.sh dc1 on|off
  ./smpro-power.sh dc2 on|off
  ./smpro-power.sh dc3 on|off
  ./smpro-power.sh dc4 on|off
  ./smpro-power.sh all on|off
  ./smpro-power.sh status
```

```
  smpro-power.py dc1 on | off
  smpro-power.py dc2 on | off
  smpro-power.py dc3 on | off
  smpro-power.py dc4 on | off
  smpro-power.py all on | off
  smpro-power.py status
```
